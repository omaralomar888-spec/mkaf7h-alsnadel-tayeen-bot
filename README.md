# MkAF7h ALsNaDeL Tayeen Bot

بوت ديسكورد لنظام طلب تعيين.

## Render Start Command

```bash
npm start
```

## Environment Variables

- TOKEN
- OWNER_ID
- REQUEST_CHANNEL_ID
- ADMIN_CHANNEL_ID
- IDS_CHANNEL_ID
- AUTO_SEND_PANEL

اجعل AUTO_SEND_PANEL=true أول تشغيل فقط لإرسال لوحة الطلب، ثم غيّرها إلى false.
